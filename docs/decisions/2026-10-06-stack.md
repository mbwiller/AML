# 2026-10-06 — Framework and stack

**Context.** Content-heavy, math-heavy static site with sprinkled interactivity, two developers, no backend, weekly content growth, must look excellent.

**Options.** Astro 7 + React islands; Next.js 16 static export; Vite SPA; Docusaurus/Starlight.

**Decision.** Astro 7 (static) with MDX content collections, React 19 islands, build-time KaTeX on the unified pipeline (`markdown.processor: unified()`, KaTeX pinned via pnpm override), Tailwind v4 tokens, Base UI primitives, Mafs + D3 + Motion, a d3-force SVG concept graph, ts-fsrs + Dexie; hosted on whatever is free (Vercel Hobby or local preview; the static build is portable).

**Consequences.** Zero JS for prose; explicit hydration per widget; typed content that fails the build on broken references; two gotchas to remember (processor override; KaTeX version pin). Full memo: `docs/reference/tech-stack.md`.
