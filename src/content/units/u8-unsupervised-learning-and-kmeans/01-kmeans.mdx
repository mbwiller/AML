## Learning without labels

Every model so far learned from pairs $(x^{(i)}, y^{(i)})$. L10 turns to datasets with no $y$ at all <SlideRef lecture={10} pages="22" />.

<Definition id="def-8-1-1" title="Unsupervised learning" source="L10 pp.22, 36">

An unlabeled dataset is $\mathcal{D} = \{x^{(i)}\}_{i=1}^{n}$ with each $x^{(i)} \in \mathbb{R}^d$ a vector of $d$ features <SlideRef lecture={10} pages="36" />. Unsupervised learning finds structure in such a dataset. L10 lists four tasks <SlideRef lecture={10} pages="22-28" />:

1. **Clustering**: groups of related points, for example customer segmentation (how many groups is enough?).
2. **Outlier detection**: is a new point normal? This needs a model of the data-generating distribution, that is, density estimation.
3. **Denoising**: for example, model an image as generated by several Gaussians, cluster the pixels with a Gaussian mixture, and remove the cluster labeled as noise.
4. **Dimensionality reduction**: named only; it is a later unit (PCA).

Also written as: "learning without a teacher" (ESL ch. 14).

</Definition>

The components of a learning problem from lesson 1.1 carry over with one change <SlideRef lecture={10} pages="37" />. An unsupervised algorithm still has a model class, an objective that says how good a model is, and an optimizer that searches the class. The objective cannot use labels, because there are none.

L10 pp.30–35 run the course's first unsupervised model on the **Iris** data: 150 flowers, of which only sepal length and sepal width are used, plotted without their species <SlideRef lecture={10} pages="30" />. `KMeans(n_clusters=3)` returns three centers at about $(5.0, 3.4)$, $(5.8, 2.7)$, and $(6.8, 3.1)$ cm <SlideRef lecture={10} pages="32-33" />. Coloring the same points by species afterwards shows one clean cluster (Setosa) and two that overlap in these two features <SlideRef lecture={10} pages="34-35" />. The labels are used only to inspect the result, never to fit it.

## The k-means model and objective

<Definition id="def-8-1-2" title="k-means model" source="L10 pp.39, 41">

Fix the number of clusters $K$. A k-means model is a set of $K$ centroids $c_1, \dots, c_K \in \mathbb{R}^d$ together with the assignment function

$$f : \mathbb{R}^d \to \{1, \dots, K\}, \qquad f(x) = \argmin_{k} \lVert x - c_k \rVert_2,$$

which sends each input to the cluster of its nearest centroid. We write $z^{(i)} = f(x^{(i)})$ for the cluster of training point $i$ and $C_k = \{i : z^{(i)} = k\}$, $n_k = |C_k|$, for the members of cluster $k$. A centroid is a representative point of its cluster, not necessarily a data point <SlideRef lecture={10} pages="41" />.

Also written as: $\mu_k$ for $c_k$ (CS229, PRML); "cluster ID" for $z$.

</Definition>

<Definition id="def-8-1-3" title="k-means objective" source="L10 p.40 (normalized: squared norm)">

The k-means objective is the average squared [[euclidean-distance|Euclidean distance]] from each point to its assigned centroid:

$$
J(c, z) = \frac{1}{n}\sum_{i=1}^{n} \big\lVert x^{(i)} - c_{z^{(i)}} \big\rVert_2^2 . \tag{8.1.1} \htmlId{eq-8-1-1}{}
$$

The model is fit by minimizing $J$ jointly over the centroids $c = (c_1, \dots, c_K)$ and the assignments $z = (z^{(1)}, \dots, z^{(n)})$.

Also written as: within-cluster sum of squares, distortion, or **inertia** for $nJ$ (sklearn's `inertia_`; `model.score(X)` returns $-nJ$).

</Definition>

<Callout type="slide">

L10 p.40 writes the objective as $J(f) = \frac1n\sum_i \lVert x^{(i)} - \mathrm{centroid}(f(x^{(i)}))\rVert$ with $\mathrm{centroid}(k) = c_k$: the norm is **not squared** <SlideRef lecture={10} pages="40" />. We square it, because the update step on p.41 and p.47 ("recalculate centroids as the average") minimizes the squared version and not the un-squared one (der-8-1-3), and sklearn's inertia is squared. L10 p.47 writes $x(i)$ for $x^{(i)}$ and $f(x(i))$ for our $z^{(i)}$. The figure on p.40, a triangle with its medians meeting at the "centroid", is the same word in its geometric sense: the centroid of three vertices is their mean.

</Callout>

<Definition id="def-8-1-4" title="Lloyd's algorithm (k-means clustering)" source="L10 pp.41, 47">

1. Choose $K$ and initial centroids $c_1, \dots, c_K$ (for example, $K$ randomly chosen data points).
2. Repeat:
   - **Assignment step.** Assign each point to its nearest centroid.
   - **Update step.** Move each centroid to the mean of the points assigned to it.

$$
z^{(i)} \leftarrow \argmin_{k} \big\lVert x^{(i)} - c_k \big\rVert_2^2, \qquad c_k \leftarrow \frac{1}{n_k}\sum_{i \in C_k} x^{(i)}
$$

3. Stop when no point changes cluster.

Ties in the assignment step are broken by keeping the current cluster if it is among the nearest, and otherwise taking the smallest index; at the first assignment, when there is no current cluster, take the smallest nearest index. A cluster that loses all its points keeps its centroid. (Both rules are ours; the slides do not discuss ties or empty clusters.)

Also written as: "k-means" (the algorithm and the objective share the name); naive k-means.

</Definition>

<Check ids={["q-u8-l1-019"]} />

<Intuition>

Take $d = 1$, $K = 2$, and six points $1, 2, 4, 9, 10, 12$ (toy values) with starting centroids $c_1 = 1$, $c_2 = 4$.

- **Assign.** Each point goes to the nearer centroid, so the boundary is the midpoint $2.5$: clusters $\{1, 2\}$ and $\{4, 9, 10, 12\}$. Then $J = \tfrac16(0 + 1 + 0 + 25 + 36 + 64) = 21$.
- **Update.** The means are $1.5$ and $8.75$. Same clusters, new centroids: $J = 5.875$.
- **Assign.** The midpoint is now $5.125$, so the point 4 switches to cluster 1: $J = 3.15625$.
- **Update.** The means are $7/3$ and $31/3$: $J = 14/9 \approx 1.556$.
- **Assign.** The midpoint $19/3 \approx 6.33$ separates the same two groups. Nothing moves, so the algorithm stops.

Two patterns are visible. Every half-step before the last lowered $J$ ($21 \to 5.875 \to 3.156 \to 1.556$), and the assignment step always cut the line at the midpoint between the centroids. The next derivations show both patterns hold in general.

</Intuition>

## The assignment step minimizes J over z

Lloyd's algorithm never mentions $J$. The key observation is that each of its two steps solves an easy half of the problem $\min_{c, z} J(c, z)$ exactly: one block of variables with the other held fixed. That is [[coordinate-descent|coordinate descent]].

<Derivation
  id="der-8-1-1"
  title="The assignment step minimizes J over the assignments"
  goalTex="\min_{z} J(c, z) \text{ for fixed centroids } c_1, \dots, c_K"
  resultTex="z^{(i)} = \argmin_{k} \lVert x^{(i)} - c_k \rVert_2^2 \text{ for each } i, \qquad J(c, z_{\text{new}}) = \min_{z} J(c, z) \le J(c, z_{\text{old}})"
  source="L10 p.47 (stated as the update rule, not as a minimization; course map L10 derivation gap 6)"
>

<Chunk title="Split J into one term per point">

<Step justification="the k-means objective (equation 8.1.1); with the centroids fixed, the only variables are the $n$ cluster labels">
$$J(c, z) = \frac{1}{n}\sum_{i=1}^{n} \big\lVert x^{(i)} - c_{z^{(i)}} \big\rVert_2^2$$
</Step>

<Step justification="term $i$ depends on $z^{(i)}$ alone, and no constraint links different points' labels, so the sum is minimized by minimizing each term on its own" fadeable>
$$\min_{z} J(c, z) = \frac{1}{n}\sum_{i=1}^{n} \min_{z^{(i)} \in \{1, \dots, K\}} \big\lVert x^{(i)} - c_{z^{(i)}} \big\rVert_2^2$$
</Step>

</Chunk>

<Chunk title="Minimize each term over K choices">

<Step justification="a function on a finite set attains its minimum; the minimizing label is the argmin" sticky="argmax">
$$z^{(i)} = \argmin_{k} \big\lVert x^{(i)} - c_k \big\rVert_2^2$$
</Step>

<Step justification="$t \mapsto t^2$ is increasing on $[0, \infty)$, so squaring a distance does not change which centroid is nearest; this is the slide's rule with the un-squared norm" sticky="euclidean-distance" fadeable>
$$\argmin_{k} \big\lVert x^{(i)} - c_k \big\rVert_2^2 = \argmin_{k} \big\lVert x^{(i)} - c_k \big\rVert_2$$
</Step>

<Step justification="if several centroids are equally near, every choice gives the same value of $J$; the tie rule of def-8-1-4 (keep the current label if it is among the nearest) makes the step a well-defined function and is used again in der-8-1-4">
$$z^{(i)}_{\text{new}} = \begin{cases} z^{(i)}_{\text{old}} & \text{if } c_{z^{(i)}_{\text{old}}} \text{ is among the nearest,} \\ \text{the smallest nearest } k & \text{otherwise} \end{cases}$$
</Step>

<Step justification="each term of step 2 is at its minimum, so the sum is at its minimum; any other assignment, including the old one, is at least as large" fadeable>
$$J(c, z_{\text{new}}) = \min_{z} J(c, z) \le J(c, z_{\text{old}})$$
</Step>

</Chunk>

</Derivation>

Step 4 is why the slide's p.47 rule, written with $\lVert \cdot \rVert_2$, is still correct for the assignment step. The square matters only in the update step.

## The update step: the mean minimizes squared distance

With the assignments fixed, each centroid solves a smooth, unconstrained problem. We set its [[gradient]] to zero (the [[first-order-condition|first-order condition]]) and then check, using [[convex-function|convexity]], that the critical point is a minimum.

<Derivation
  id="der-8-1-2"
  title="The update step: the cluster mean minimizes the sum of squared distances"
  goalTex="\min_{c_1, \dots, c_K} J(c, z) \text{ for fixed assignments } z"
  resultTex="c_k = \bar x_k = \frac{1}{n_k}\sum_{i \in C_k} x^{(i)}, \qquad \sum_{i \in C_k} \lVert x^{(i)} - v \rVert_2^2 = \sum_{i \in C_k} \lVert x^{(i)} - \bar x_k \rVert_2^2 + n_k \lVert v - \bar x_k \rVert_2^2"
  source="L10 pp.41, 47 (stated: 'recalculate centroids as the average'; course map L10 derivation gap 6)"
>

<Chunk title="Separate the centroids">

<Step justification="regroup the finite sum in equation 8.1.1 by cluster; write $G_k(v) = \sum_{i \in C_k} \lVert x^{(i)} - v \rVert_2^2$ for the cost of cluster $k$ with its centroid at a point $v \in \mathbb{R}^d$">
$$J(c, z) = \frac{1}{n}\sum_{k=1}^{K} G_k(c_k)$$
</Step>

<Step justification="$c_k$ appears only in $G_k$, so minimize each $G_k$ separately; assume $n_k \ge 1$ (an empty cluster has $G_k = 0$ for every $c_k$)">
$$\min_{c_1, \dots, c_K} J(c, z) = \frac{1}{n}\sum_{k=1}^{K} \min_{v} G_k(v)$$
</Step>

</Chunk>

<Chunk title="Set the gradient to zero">

<Step justification="$\lVert x - v \rVert_2^2 = (x - v)^\top(x - v)$; its gradient in $v$ is $-2(x - v)$" sticky="gradient">
$$\nabla_v \lVert x - v \rVert_2^2 = -2(x - v)$$
</Step>

<Step justification="the gradient of a sum is the sum of the gradients; $\sum_{i \in C_k} v = n_k v$">
$$\nabla G_k(v) = -2\Big(\sum_{i \in C_k} x^{(i)} - n_k\, v\Big)$$
</Step>

<Step justification="set the gradient to zero and divide by $n_k$; call the solution $\bar x_k$, the cluster mean" sticky="first-order-condition" fadeable>
$$v = \frac{1}{n_k}\sum_{i \in C_k} x^{(i)} =: \bar x_k$$
</Step>

</Chunk>

<Chunk title="Confirm it is the minimum">

<Step justification="differentiate step 4 once more: the Hessian is a positive multiple of the identity, so $G_k$ is strictly convex and its only critical point is its global minimum" sticky="hessian">
$$\nabla^2 G_k(v) = 2 n_k I \succ 0$$
</Step>

<Step justification="write $x^{(i)} - v = (x^{(i)} - \bar x_k) + (\bar x_k - v)$ in each term and expand the square">
$$G_k(v) = \sum_{i \in C_k} \lVert x^{(i)} - \bar x_k \rVert_2^2 + 2(\bar x_k - v)^\top \sum_{i \in C_k}(x^{(i)} - \bar x_k) + n_k \lVert \bar x_k - v \rVert_2^2$$
</Step>

<Step justification="the cross term is 0 because deviations from the mean sum to zero: $\sum_{i \in C_k}(x^{(i)} - \bar x_k) = n_k \bar x_k - n_k \bar x_k$ (step 5)" fadeable>
$$G_k(v) = G_k(\bar x_k) + n_k \lVert v - \bar x_k \rVert_2^2$$
</Step>

</Chunk>

</Derivation>

Step 8 says more than "the mean is optimal". Moving a centroid from $v$ to the mean lowers its cluster's cost by exactly $n_k \lVert v - \bar x_k \rVert_2^2$, so the decrease is strict whenever the centroid actually moves.

<Callout type="note">

**Unit 7 did this calculation already.** The GDA mean $\hat\mu_k$ (lesson 7.2) solved the same first-order condition, because the [[multivariate-gaussian|Gaussian]] log-density is $-\tfrac12(x - \mu)^\top\Sigma^{-1}(x - \mu)$ plus a constant. With $\Sigma = \sigma^2 I$ that is $-\lVert x - \mu \rVert_2^2 / (2\sigma^2)$. Maximizing a Gaussian likelihood and minimizing squared distance pick the same center. The difference is that GDA knows which points belong to which class and k-means has to guess.

</Callout>

## Why the slide's un-squared norm breaks the algorithm

If we kept the slide's $J$, the assignment step would still be right (der-8-1-1 step 4), but the update step would be minimizing the wrong thing.

<Derivation
  id="der-8-1-3"
  title="With the un-squared norm, the best centroid is the geometric median, not the mean"
  goalTex="\min_{c} H(c), \qquad H(c) = \sum_{i \in C_k} \lVert x^{(i)} - c \rVert_2"
  resultTex="c^\star = \argmin_c H(c) \text{ (geometric median; in 1-D, the median)}; \text{ if } c^\star \notin \{x^{(i)}\}: \sum_{i \in C_k} \frac{x^{(i)} - c^\star}{\lVert x^{(i)} - c^\star \rVert_2} = 0; \text{ not the mean in general}"
  source="L10 p.40 (un-squared J) against L10 pp.41, 47 (mean update); course map L10 derivation gap 6 and slide error L10 p.40"
>

<Chunk title="Differentiate the un-squared distance">

<Step justification="chain rule on $\sqrt{u}$ with $u = (x - c)^\top(x - c)$: $\frac{1}{2\sqrt u}$ times $\nabla_c u = -2(x - c)$; valid for $c \ne x$" sticky="chain-rule-calculus">
$$\nabla_c \lVert x - c \rVert_2 = -\frac{x - c}{\lVert x - c \rVert_2}$$
</Step>

<Step justification="sum over the cluster; each term is a unit vector pointing from $c$ toward a data point, so every point pulls with the same strength however far away it is">
$$\nabla H(c) = -\sum_{i \in C_k} \frac{x^{(i)} - c}{\lVert x^{(i)} - c \rVert_2}$$
</Step>

<Step justification="first-order condition at a $c$ that is not a data point: the unit vectors toward the points balance. $H$ is convex as a sum of norms, so such a stationary point is the global minimum, called the geometric median. If the minimizer is a data point, $H$ is not differentiable there and this condition does not apply; the 1-D example below is such a case" sticky="first-order-condition" fadeable>
$$\sum_{i \in C_k} \frac{x^{(i)} - c}{\lVert x^{(i)} - c \rVert_2} = 0$$
</Step>

</Chunk>

<Chunk title="Compare with the mean">

<Step justification="write $w_i = 1 / \lVert x^{(i)} - c \rVert_2$ and solve step 3 for $c$: a weighted mean whose weights depend on $c$; the plain mean has equal weights, so the two agree only when the mean happens to satisfy the balance condition of step 3, which fails in general" fadeable>
$$c = \frac{\sum_{i \in C_k} w_i\, x^{(i)}}{\sum_{i \in C_k} w_i}$$
</Step>

<Step justification="a 1-D counterexample: the points $0, 0, 3$ give $H(c) = 2|c| + |3 - c|$; evaluate at the mean $c = 1$ and at $c = 0$" fadeable>
$$H(1) = 2 + 2 = 4 \;>\; H(0) = 0 + 3 = 3$$
</Step>

<Step justification="in 1-D, $H$ has slope (number of points left of $c$) minus (number right of $c$) away from the data points, which changes sign at the median; here the median is 0">
$$\argmin_{c} \sum_{i} |x^{(i)} - c| = \operatorname{median}\{x^{(i)}\} = 0 \ne 1 = \text{mean}$$
</Step>

</Chunk>

<Chunk title="The consequence for Lloyd's algorithm">

<Step justification="a cluster $\{0, 0, 3\}$ whose centroid sits at 0 has un-squared cost 3; the mean update moves it to 1 and the cost rises to 4, so with the slide's $J$ an iteration of the algorithm can increase the objective">
$$\sum_i |x^{(i)} - 0| = 3 \;\longrightarrow\; \sum_i |x^{(i)} - 1| = 4$$
</Step>

</Chunk>

</Derivation>

So the slide's objective and the slide's algorithm do not match. The mean update belongs to the squared objective; the un-squared objective would need a geometric-median update (k-median clustering with the Euclidean distance). Its $\ell_1$ cousin, k-medians, uses the $\ell_1$ distance and coordinate-wise medians; with representatives restricted to data points, the method is k-medoids. The geometric-median update is more robust to outliers, because a far point pulls with strength 1 instead of strength proportional to its distance.

<Check ids={["q-u8-l1-009", "q-u8-l1-011", "q-u8-l1-014"]} />

## Lloyd's algorithm never increases J and always stops

Now put the two steps together. Index the iterations by $t$: $z^{(t+1)}$ is the assignment computed from $c^{(t)}$, and $c^{(t+1)}$ the centroids computed from $z^{(t+1)}$. For $t \ge 1$ write $J^{(t)} = J(c^{(t)}, z^{(t)})$.

<Derivation
  id="der-8-1-4"
  title="Lloyd's algorithm is monotone and terminates in finitely many iterations"
  goalTex="J^{(t+1)} \le J^{(t)}, \text{ and the assignments stop changing after finitely many iterations}"
  resultTex="J^{(1)} \ge J^{(2)} \ge \cdots \ge 0, \text{ strictly while any point moves; at most } K^n \text{ iterations change the assignment}"
  source="L10 pp.41, 47 (stated: 'terminate when no observations get reassigned'; convergence not argued; course map L10 derivation gap 6)"
>

<Chunk title="Each half-step is a block minimization">

<Step justification="the assignment step minimizes $J$ over $z$ with $c^{(t)}$ fixed (der-8-1-1 step 6)" sticky="coordinate-descent">
$$J(c^{(t)}, z^{(t+1)}) \le J(c^{(t)}, z^{(t)})$$
</Step>

<Step justification="the update step minimizes $J$ over $c$ with $z^{(t+1)}$ fixed (der-8-1-2); an empty cluster contributes 0 whatever its centroid">
$$J(c^{(t+1)}, z^{(t+1)}) \le J(c^{(t)}, z^{(t+1)})$$
</Step>

<Step justification="chain steps 2 and 1" fadeable>
$$J^{(t+1)} \le J^{(t)}$$
</Step>

<Step justification="$J$ is an average of squared norms, so it is bounded below by 0; a non-increasing sequence that is bounded below converges">
$$J^{(t)} \ge 0 \text{ for all } t \quad\Longrightarrow\quad J^{(t)} \text{ converges}$$
</Step>

</Chunk>

<Chunk title="After an update, J depends only on the partition">

<Step justification="define $g(z)$ as the best $J$ for a given assignment; by der-8-1-2 the update step attains it, so for $t \ge 1$ the value $J^{(t)}$ is a function of $z^{(t)}$ alone">
$$g(z) = \min_{c} J(c, z), \qquad J^{(t)} = g(z^{(t)})$$
</Step>

<Step justification="each of the $n$ points has $K$ possible labels, so there are finitely many assignments and $g$ takes finitely many values">
$$\big|\{1, \dots, K\}^n\big| = K^n$$
</Step>

</Chunk>

<Chunk title="Any reassignment strictly lowers J">

<Step justification="if $z^{(t+1)} \ne z^{(t)}$, the tie rule (der-8-1-1 step 5) moved some point only because its new centroid is strictly nearer, and no point moved farther" fadeable>
$$z^{(t+1)} \ne z^{(t)} \;\Longrightarrow\; J(c^{(t)}, z^{(t+1)}) < J(c^{(t)}, z^{(t)})$$
</Step>

<Step justification="the left inequality holds because $g$ is a minimum over $c$; the middle one is step 7; the right equality is step 5, valid for $t \ge 1$ because $c^{(t)}$ was computed from $z^{(t)}$">
$$g(z^{(t+1)}) \le J(c^{(t)}, z^{(t+1)}) < J(c^{(t)}, z^{(t)}) = g(z^{(t)})$$
</Step>

<Step justification="a strictly decreasing sequence of values of $g$ never repeats, so no assignment is visited twice; with $K^n$ assignments (step 6), the assignment can change at most $K^n$ times">
$$\#\{t : z^{(t+1)} \ne z^{(t)}\} \le K^n$$
</Step>

</Chunk>

<Chunk title="What the algorithm stops at">

<Step justification="once no point is reassigned, the update step recomputes the same means (and empty clusters keep their centroids), so every later iteration repeats: this is the slide's stopping rule">
$$z^{(t+1)} = z^{(t)} \;\Longrightarrow\; c^{(t+1)} = c^{(t)}$$
</Step>

<Step justification="at the stopping point neither block can be improved alone: no single reassignment and no centroid move lowers $J$; that is a local minimum in this sense, not necessarily the global one" sticky="local-minimum">
$$J(c^{(t)}, z^{(t)}) = \min_{z} J(c^{(t)}, z) = \min_{c} J(c, z^{(t)})$$
</Step>

</Chunk>

</Derivation>

The bound $K^n$ is enormous and says nothing about speed. In practice Lloyd's algorithm usually stops after a few dozen iterations. The proof's value is the guarantee: it cannot cycle, and it cannot make things worse.

<Callout type="beyond">

The termination argument needs the tie rule. Without it, a point exactly halfway between two centroids could flip back and forth while $J$ stays the same, and step 7 would fail. Implementations either fix a rule like ours or stop when the centroids move by less than a tolerance (sklearn's `tol` bounds the change in the cluster centers between iterations), which is the [[convergence-criterion]] of gradient descent in a new setting.

</Callout>

## Clusters are convex Voronoi cells

The intuition example cut the line at the midpoint between two centroids. In $d$ dimensions the assignment step cuts space into the [[voronoi-partition|Voronoi cells]] of the centroids, the black boundary lines in the Wikipedia animation on L10 pp.42–43 <SlideRef lecture={10} pages="42-43" />.

<Derivation
  id="der-8-1-5"
  title="Each k-means cluster is a convex region bounded by perpendicular bisectors"
  goalTex="V_k = \{x : \lVert x - c_k \rVert_2 \le \lVert x - c_l \rVert_2 \text{ for all } l \ne k\} \text{ is convex}"
  resultTex="V_k = \bigcap_{l \ne k} \Big\{x : (c_l - c_k)^\top\big(x - \tfrac12(c_k + c_l)\big) \le 0\Big\}, \text{ an intersection of half-spaces, hence convex}"
  source="beyond the slides (L10 pp.42-43, 48 show the cells; course map L10 refresher 'Argmin / Voronoi partition')"
>

<Chunk title="Turn one comparison into a linear inequality">

<Step justification="definition of the cell; comparing squared distances gives the same set, since squaring is increasing on $[0, \infty)$" sticky="voronoi-partition">
$$V_k = \bigcap_{l \ne k} \big\{x : \lVert x - c_k \rVert_2^2 \le \lVert x - c_l \rVert_2^2\big\}$$
</Step>

<Step justification="expand the squared norm as an inner product" sticky="euclidean-distance">
$$\lVert x - c \rVert_2^2 = \lVert x \rVert_2^2 - 2c^\top x + \lVert c \rVert_2^2$$
</Step>

<Step justification="substitute step 2 for $c_k$ and $c_l$ into one comparison; the $\lVert x \rVert_2^2$ terms cancel, which leaves an inequality that is linear in $x$" fadeable>
$$2(c_l - c_k)^\top x \le \lVert c_l \rVert_2^2 - \lVert c_k \rVert_2^2$$
</Step>

<Step justification="difference of squares: $\lVert c_l \rVert_2^2 - \lVert c_k \rVert_2^2 = (c_l - c_k)^\top(c_l + c_k)$">
$$2(c_l - c_k)^\top x \le (c_l - c_k)^\top(c_l + c_k)$$
</Step>

<Step justification="divide by 2 and move the right-hand side to the left: the boundary is the hyperplane through the midpoint, perpendicular to $c_l - c_k$" fadeable>
$$(c_l - c_k)^\top\Big(x - \tfrac12(c_k + c_l)\Big) \le 0$$
</Step>

</Chunk>

<Chunk title="Half-spaces are convex, and so are their intersections">

<Step justification="for $a, b$ in the half-space $\{x : w^\top x \le \beta\}$ and $\lambda \in [0, 1]$, linearity of $w^\top x$ keeps the convex combination inside">
$$w^\top\big(\lambda a + (1 - \lambda) b\big) = \lambda\, w^\top a + (1 - \lambda)\, w^\top b \le \lambda\beta + (1 - \lambda)\beta = \beta$$
</Step>

<Step justification="a segment between two points of $V_k$ lies in every half-space of step 5 (by step 6), hence in their intersection" fadeable>
$$a, b \in V_k,\ \lambda \in [0, 1] \;\Longrightarrow\; \lambda a + (1 - \lambda) b \in V_k$$
</Step>

</Chunk>

</Derivation>

Step 3 is the same cancellation that made the shared-covariance GDA boundary linear (der-7-3-1 step 7): both sides carry the same quadratic term in $x$. Here it says that k-means can only draw straight walls between clusters. Two consequences:

- **k-means prefers round, similar-size clusters.** A long, thin cluster next to a compact one gets cut by the perpendicular bisector of their centroids, which slices through the long one. That is why the L10 p.49 poll's statement (b) is false.
- **The model generalizes.** $f(x) = \argmin_k \lVert x - c_k \rVert_2$ is defined for any new $x$, so a fitted k-means model assigns new patients to clusters by which cell they fall in.

## Feature scaling

L10 p.44 measures closeness with the Euclidean distance, $\sqrt{(a_1 - b_1)^2 + \dots + (a_d - b_d)^2}$ <SlideRef lecture={10} pages="44" />. Every feature enters that sum on equal terms, whatever its units, so a feature's [[variance]] decides its weight, and its [[z-score]] removes the units. The L10 p.45 poll asks what that implies <SlideRef lecture={10} pages="45" />.

<Derivation
  id="der-8-1-6"
  title="A feature's share of the squared distance is proportional to its variance"
  goalTex="\text{the contribution of feature } j \text{ to } \lVert a - b \rVert_2^2, \text{ averaged over pairs of data points}"
  resultTex="\frac{1}{n^2}\sum_{i, i'} \lVert x^{(i)} - x^{(i')} \rVert_2^2 = 2\sum_{j=1}^{d} s_j^2, \qquad \text{share of feature } j = \frac{s_j^2}{\sum_{l} s_l^2} \;\xrightarrow{\text{z-score}}\; \frac{1}{d}"
  source="beyond the slides (L10 pp.44-46 state the problem and the z-score; course map L10 derivation gap 8)"
>

<Chunk title="Each feature adds its own term">

<Step justification="the squared Euclidean distance is a sum over features" sticky="euclidean-distance">
$$\lVert a - b \rVert_2^2 = \sum_{j=1}^{d} (a_j - b_j)^2$$
</Step>

<Step justification="changing the units of feature $j$ multiplies its values by a constant $\alpha$ ($\alpha = 365$ for years to days), so its term is multiplied by $\alpha^2$" fadeable>
$$(\alpha\,a_j - \alpha\,b_j)^2 = \alpha^2 (a_j - b_j)^2$$
</Step>

</Chunk>

<Chunk title="Average over all pairs of points">

<Step justification="define $D_j$ as feature $j$'s term averaged over all $n^2$ ordered pairs of data points">
$$D_j = \frac{1}{n^2}\sum_{i=1}^{n}\sum_{i'=1}^{n}\big(x_j^{(i)} - x_j^{(i')}\big)^2$$
</Step>

<Step justification="expand the square">
$$D_j = \frac{1}{n^2}\sum_{i=1}^{n}\sum_{i'=1}^{n}\Big[(x_j^{(i)})^2 - 2x_j^{(i)}x_j^{(i')} + (x_j^{(i')})^2\Big]$$
</Step>

<Step justification="each squared term does not depend on the other index, so each averages to $\frac1n\sum_i (x_j^{(i)})^2$">
$$D_j = \frac{2}{n}\sum_{i=1}^{n}(x_j^{(i)})^2 - \frac{2}{n^2}\sum_{i=1}^{n}\sum_{i'=1}^{n} x_j^{(i)}x_j^{(i')}$$
</Step>

<Step justification="the double sum of the product factors as $\big(\sum_i x_j^{(i)}\big)^2 = n^2\bar x_j^2$">
$$D_j = \frac{2}{n}\sum_{i=1}^{n}(x_j^{(i)})^2 - 2\bar x_j^2$$
</Step>

<Step justification="the mean of the squares minus the square of the mean is the variance; here $s_j^2 = \frac1n\sum_i (x_j^{(i)} - \bar x_j)^2$" sticky="variance" fadeable>
$$D_j = 2 s_j^2$$
</Step>

<Step justification="sum over features using step 1; feature $j$ supplies the fraction $D_j / \sum_l D_l$ of the average squared distance">
$$\frac{1}{n^2}\sum_{i, i'} \lVert x^{(i)} - x^{(i')} \rVert_2^2 = 2\sum_{j=1}^{d} s_j^2, \qquad \frac{D_j}{\sum_l D_l} = \frac{s_j^2}{\sum_l s_l^2}$$
</Step>

</Chunk>

<Chunk title="Standardize">

<Step justification="the z-score $\tilde x_j = (x_j - \bar x_j)/s_j$ has standard deviation 1 for every feature, so in step 8 every share is the same" sticky="z-score" fadeable>
$$\tilde s_j = 1 \text{ for all } j \;\Longrightarrow\; \frac{\tilde s_j^2}{\sum_l \tilde s_l^2} = \frac{1}{d}$$
</Step>

</Chunk>

</Derivation>

A feature with a large spread (a large variance) dominates the distance, so it dominates both the assignment step and $J$. That answers the p.45 poll: k-means is sensitive to units; the L2 distance is driven by the variables of **larger** scale, not smaller; and it is hard to compare, say, days with miles in one distance. L10 p.46's fix is to express every variable as a number of standard deviations from its mean, its z-score <SlideRef lecture={10} pages="46" />:

$$\text{normalized data} = \frac{\text{data} - \text{sample mean}}{\text{sample standard deviation}}.$$

<Callout type="note">

**Scaling in k-means is not scaling in regression.** In lesson 2.5 standardizing features changed how fast gradient descent converged but not the fitted predictions, because the weights absorb any change of units. k-means has no weights to absorb it: rescaling a feature changes which centroid is nearest, so it changes the answer itself. Equal shares after z-scoring is also a choice, not a law. If one feature matters more clinically, you can weight it on purpose; the problem is weighting it by accident of units.

</Callout>

## Local minima and initialization

der-8-1-4 guarantees a stopping point, not a good one. The problem $\min_{c, z} J$ is non-[[convex-function|convex]]: the assignments $z$ are discrete, and minimizing them out leaves $\min_z J(c, z) = \frac1n\sum_i \min_k \lVert x^{(i)} - c_k \rVert_2^2$, which is not convex in $c$. Lloyd's algorithm can stop at a poor [[local-minimum]].

A toy example: four points at the corners of a wide rectangle, $(0, 0)$, $(0, 1)$, $(4, 0)$, $(4, 1)$, with $K = 2$. The good clustering is left pair and right pair, with centroids $(0, 0.5)$ and $(4, 0.5)$ and $J = 0.25$. Now start the centroids at $(2, 0)$ and $(2, 1)$. Each bottom point is at squared distance 4 from $(2, 0)$ and 5 from $(2, 1)$, so it stays at the bottom; the top points stay at the top. The means of the two pairs are the starting centroids. Nothing moves, and the algorithm stops with $J = 4$, sixteen times worse. This is the p.49 poll's statement (c), and it is why statement (a) is false: different starting centroids give different answers.

Two standard remedies, neither on the slides:

- **Restarts.** Run Lloyd's algorithm from several initializations and keep the run with the smallest $J$. In sklearn, `n_init` sets the number of runs.
- **Better seeding.** Spread the initial centroids out, so that two of them rarely start inside the same true cluster.

<Proof collapsed title="k-means++ seeding and its guarantee (stated, not proved)" keyIdea="choose each new seed with probability proportional to its squared distance from the seeds already chosen">

**Algorithm** (Arthur and Vassilvitskii, 2007). Pick the first centroid uniformly at random from the data points. Then, for each of the remaining $K - 1$ centroids, let $D(x^{(i)})$ be the distance from $x^{(i)}$ to the nearest centroid chosen so far, and pick $x^{(i)}$ as the next centroid with probability

$$\frac{D(x^{(i)})^2}{\sum_{i'} D(x^{(i')})^2}.$$

A point far from every existing seed is likely to be chosen, and a point already covered is not. After seeding, run Lloyd's algorithm as usual.

**Guarantee.** Let $J_{\text{opt}}$ be the smallest possible value of the objective with $K$ clusters. The seeding alone (before any Lloyd's iteration) satisfies

$$\mathbb{E}\big[J_{\text{seed}}\big] \le 8(\ln K + 2)\, J_{\text{opt}},$$

where the expectation is over the random choices. So k-means++ is $O(\log K)$-competitive with the optimum in expectation, and Lloyd's algorithm can only lower $J$ from there (der-8-1-4). Random seeding has no such guarantee. sklearn's `KMeans` uses k-means++ seeding by default (`init="k-means++"`). We state the bound without proof; the proof is in the original paper.

</Proof>

## Choosing K with the elbow method

The slides fix $K = 3$ for Iris and ask "how many groups is enough?" without answering <SlideRef lecture={10} pages="23" />. The lecture10 companion answers with the elbow method. It is beyond the slides.

The companion generates 100 points from four Gaussian blobs (`make_blobs(centers=4)`, seed 0) and fits k-means with several $K$ <Notebook path="Lectures/lecture10-unsupervised-learning code companion.ipynb" cells="11-35" />. It prints the objective as `-model.score(X)`, which is the inertia $nJ$:

- $K = 2$: inertia 462.03, so $J = 4.6203$ per point. Two clusters cannot cover four blobs; the companion calls this underfitting.
- $K = 50$: inertia 5.46, so $J = 0.0546$. Fifty centroids fit "small, local noise clusters"; the companion calls this overfitting.

The smallest achievable $J$ can only go down as $K$ grows, because a solution with $K$ centroids plus one extra centroid placed on any data point is at least as good. (A particular run of Lloyd's algorithm need not follow this, since it may stop at a local minimum.) At $K = n$, with distinct points, each point is its own centroid and $J = 0$. So minimizing $J$ over $K$ always picks $K = n$, and $J$ alone cannot choose $K$.

The elbow method plots $J$ (or inertia) against $K = 1, \dots, 10$ and looks for the bend: the $K$ after which adding a cluster buys little. For the blobs the companion marks $K = 4$: "the decrease slows down after $K = 4$, after that the curve becomes just a line." It is a heuristic, a way to tune a hyperparameter without labels, and it is ambiguous when the curve bends gently. That is the p.49 poll's statement (d): measuring clustering quality is hard and relies on heuristics.

## k-means as a limit of a Gaussian mixture

<Callout type="beyond">

L10 opened with the Gaussian mixture $p(x) = \sum_k \pi_k \mathcal{N}(x; \mu_k, \Sigma_k)$ (lesson 7.1) and left open how to fit one without labels. The answer, EM, is Unit 9. k-means is its limiting case, which is why the p.49 poll's statement (e) is false: k-means assignments carry no probability, and the mixture model puts the probability back. It is also why the companion's legend calls the centroids "probability peaks": that name belongs to the mixture means, not to k-means centroids.

</Callout>

<Proof collapsed title="k-means is the σ → 0 limit of a Gaussian mixture with covariances σ²I" keyIdea="as the shared variance shrinks, the posterior over components puts all its mass on the nearest mean">

Take a mixture with weights $\pi_k > 0$ and spherical covariances $\Sigma_k = \sigma^2 I$ for every $k$. By Bayes' rule, the posterior probability that $x^{(i)}$ came from component $k$ (its responsibility) is

$$r_k^{(i)} = \frac{\pi_k \exp\!\big(-\lVert x^{(i)} - \mu_k \rVert_2^2 / 2\sigma^2\big)}{\sum_{l} \pi_l \exp\!\big(-\lVert x^{(i)} - \mu_l \rVert_2^2 / 2\sigma^2\big)},$$

because the normalizers $(2\pi\sigma^2)^{-d/2}$ are the same for every component and cancel. Let $\delta_l = \lVert x^{(i)} - \mu_l \rVert_2^2$ and suppose component $m$ is the unique nearest, $\delta_m < \delta_l$ for $l \ne m$. Divide the numerator and denominator by $\exp(-\delta_m / 2\sigma^2)$:

$$r_k^{(i)} = \frac{\pi_k \exp\!\big(-(\delta_k - \delta_m)/2\sigma^2\big)}{\pi_m + \sum_{l \ne m} \pi_l \exp\!\big(-(\delta_l - \delta_m)/2\sigma^2\big)}.$$

Each exponent with $\delta_l - \delta_m > 0$ tends to $-\infty$ as $\sigma \to 0$, so those exponentials tend to 0. Hence $r_m^{(i)} \to 1$ and $r_k^{(i)} \to 0$ for $k \ne m$: the soft assignment becomes the hard k-means assignment $z^{(i)} = \argmin_k \lVert x^{(i)} - \mu_k \rVert_2^2$, whatever the weights $\pi_k$.

In EM, the mean update is the responsibility-weighted average $\mu_k = \sum_i r_k^{(i)} x^{(i)} / \sum_i r_k^{(i)}$, the GDA mean with fractional memberships. With 0/1 responsibilities it is the plain cluster mean, the k-means update. So Lloyd's algorithm is EM for this mixture in the limit $\sigma \to 0$. With $\sigma > 0$ every point belongs a little to every cluster, which is the probabilistic confidence k-means lacks.

</Proof>

**Both features in cm.** The squared distances are sums of two squared differences (der-8-1-6 step 1):

| centroid | length term | width term | squared distance |
|---|---|---|---|
| $c_1$ | $1.2^2$ | $0.3^2$ | $1.53$ |
| $c_2$ | $0.4^2$ | $0.4^2$ | $0.32$ |
| $c_3$ | $0.6^2$ | $0^2$ | $0.36$ |

The nearest is $c_2$, narrowly. Length says $c_2$ (difference 0.4 against 0.6); width says $c_3$ (difference 0 against 0.4).

**Width recorded in mm instead.** Multiply every width by 10, the flower's and the centroids' alike. By der-8-1-6 step 2 the width terms grow by a factor of 100:

| centroid | length term (cm) | width term (mm) | squared distance |
|---|---|---|---|
| $c_1$ | $1.44$ | $9$ | $10.44$ |
| $c_2$ | $0.16$ | $16$ | $16.16$ |
| $c_3$ | $0.36$ | $0$ | $0.36$ |

Now the nearest is $c_3$. Nothing about the flower changed; only the unit of one feature. Recording length in mm instead pushes the other way: the length terms become $144$, $16$, and $36$, and $c_2$ wins comfortably.

A full refit would also move the centroids, but the lesson is the same: with unscaled features, the cluster a flower lands in depends on the ruler. After z-scoring both features with their sample standard deviations (der-8-1-6 step 9), the units cancel out of every comparison and the choice no longer depends on cm versus mm.

</Example>

## Pitfalls

<Pitfall title="Spot the error: the k-means objective needs the square" misconception="kmeans-unsquared-objective">

L10 p.40 writes $J(f) = \frac1n\sum_i \lVert x^{(i)} - \mathrm{centroid}(f(x^{(i)}))\rVert$, with an un-squared norm. The update step on pp.41 and 47 moves each centroid to the mean, and the mean minimizes the sum of **squared** distances (der-8-1-2), not of distances. For the un-squared sum the minimizer is the geometric median (der-8-1-3), and with the slide's $J$ a mean update can raise the objective: the cluster $\{0, 0, 3\}$ with centroid 0 costs 3, and after moving the centroid to the mean 1 it costs 4. Use $J = \frac1n\sum_i \lVert x^{(i)} - c_{z^{(i)}}\rVert_2^2$, which is also what sklearn's inertia measures (times $n$).

</Pitfall>

<Pitfall title="k-means does not find the best clustering, or the same one every time" misconception="kmeans-global-optimum">

The belief: Lloyd's algorithm converges, so it converges to the optimal clustering, and rerunning it gives the same answer. The fix: der-8-1-4 proves convergence to a point that neither step can improve, a local minimum. The rectangle example stops at $J = 4$ when $J = 0.25$ is available, and different random initializations can stop at different points (L10 p.49 poll, statements (a) and (c)). Use several restarts and k-means++ seeding, and compare the final $J$ values.

</Pitfall>

<Pitfall title="Unscaled features let the units choose the clusters" misconception="kmeans-scale-invariant">

The belief: k-means finds the natural groups whatever units the features are recorded in, or the distance is driven by the small-scale features. The fix: each feature contributes in proportion to its variance (der-8-1-6), so the largest-scale feature dominates. Changing a time from years to days multiplies its term by $365^2$. Standardize every feature (L10 p.46) unless you mean to weight features unequally, and compute the means and standard deviations on the training data.

</Pitfall>

<Pitfall title="Centroids are not probability peaks, and assignments are not confidences" misconception="kmeans-probabilistic">

The belief: a k-means assignment says how likely a point is to belong to its cluster, and the centroids are the modes of a density. The companion's plot legend calls the centroids "Probability peaks", which invites this reading. The fix: k-means returns a hard label and nothing else (L10 p.49 poll, statement (e) is false). A point on the boundary between two cells gets a label as firmly as a point at a centroid. Probabilities and peaks come from a Gaussian mixture, of which k-means is the $\sigma \to 0$ limit; in that limit the mixture weights $\pi_k$ stop mattering, and the nearest mean wins whatever its weight.

</Pitfall>

<Pitfall title="k-means assumes round, similar-size clusters" misconception="kmeans-any-shape">

The belief: k-means works best on correlated features with elongated (ellipsoidal) clusters of different spreads. The fix: the boundaries are perpendicular bisectors between centroids (der-8-1-5), so every cluster is a convex cell and the objective rewards compact, round groups of similar size. An elongated cluster beside a compact one is cut in two (L10 p.49 poll, statement (b) is false). Gaussian mixtures with full covariances handle elongated clusters.

</Pitfall>

<Pitfall title="Do not choose K by minimizing J" misconception="kmeans-choose-k-by-j">

The belief: the best $K$ is the one with the lowest objective. The fix: the smallest achievable $J$ never increases as $K$ grows and reaches 0 at $K = n$ (for distinct points), so minimizing it always picks one cluster per point (the companion's $K = 50$ fit is the overfitting example). The elbow method looks for where the decrease slows, which is a heuristic (L10 p.49 poll, statement (d)).

</Pitfall>

<Pitfall title="sklearn's inertia is nJ, not J" misconception="kmeans-inertia-is-j">

sklearn's `inertia_` is the **sum** of squared distances to the assigned centroids, and `model.score(X)` returns its negative. The lesson's $J$ (equation 8.1.1) keeps the $\frac1n$, so $J = \text{inertia}/n$: the companion's 462.03 on 100 points is $J = 4.6203$. Comparing an inertia with a $J$, or inertias across datasets of different sizes, mixes up a total with an average.

</Pitfall>

<Pitfall title="A cluster is not a phenotype until it is validated" misconception="kmeans-clusters-are-real">

The belief: k-means found four groups in SEPSIS-4, so there are four kinds of sepsis. The fix: k-means returns $K$ groups for any $K$ you ask for, even on data with no group structure. A clustering is a hypothesis. Check it against something the algorithm never saw (the SEPSIS-4 case holds out 28-day mortality for exactly this), check its stability across restarts and resamples, and check whether it survives a change of scaling.

</Pitfall>

<Summary>

- **Unsupervised learning:** data $\{x^{(i)}\}_{i=1}^n$ with no labels; tasks are clustering, outlier detection (density estimation), denoising, and dimensionality reduction. Model class, objective, optimizer as before; the objective cannot use labels.
- **k-means:** centroids $c_1, \dots, c_K$; $z^{(i)} = \argmin_k \lVert x^{(i)} - c_k\rVert_2$; objective $J(c, z) = \frac1n\sum_i \lVert x^{(i)} - c_{z^{(i)}}\rVert_2^2$ with the **square** (L10 p.40 omits it). sklearn inertia $= nJ$.
- **Lloyd's algorithm = coordinate descent.** Assignment step: $\argmin_z J$ for fixed $c$ (nearest centroid). Update step: $\argmin_c J$ for fixed $z$ is the cluster mean, with $\sum_{i \in C_k}\lVert x^{(i)} - c\rVert_2^2 = \sum_{i \in C_k}\lVert x^{(i)} - \bar x_k\rVert_2^2 + n_k\lVert c - \bar x_k\rVert_2^2$.
- **Un-squared norm:** the minimizer is the geometric median (median in 1-D), not the mean; with the slide's $J$ the mean update can increase the objective.
- **Convergence:** $J^{(t+1)} \le J^{(t)}$, strictly whenever a point moves; finitely many ($K^n$) partitions, so it stops; the stopping point is a local minimum, not necessarily global.
- **Geometry:** cluster $k$ is the Voronoi cell $\bigcap_{l \ne k}\{x : (c_l - c_k)^\top(x - \tfrac12(c_k + c_l)) \le 0\}$, convex with straight walls; k-means favors round, similar-size clusters.
- **Scaling:** feature $j$'s share of the average squared distance is $s_j^2/\sum_l s_l^2$; z-score so units do not choose the clusters.
- **Initialization and K:** restarts and k-means++ ($\mathbb{E}[J_{\text{seed}}] \le 8(\ln K + 2)J_{\text{opt}}$); the smallest achievable $J$ is non-increasing in $K$ and is 0 at $K = n$ (distinct points), so choose $K$ at the elbow (the companion's blobs: $K = 4$).
- **Link to mixtures:** k-means is EM for a Gaussian mixture with $\Sigma_k = \sigma^2 I$ in the limit $\sigma \to 0$; it has no probabilistic assignments.

</Summary>
