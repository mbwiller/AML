**What it is.** For a square matrix $A$, the inverse $A^{-1}$ satisfies $A A^{-1} = A^{-1} A = I$. It exists exactly when $\det A \ne 0$, equivalently when $A$ has full rank and no zero eigenvalue. Two useful rules are $(AB)^{-1} = B^{-1} A^{-1}$ and $(A^\top)^{-1} = (A^{-1})^\top$, so the inverse of a symmetric matrix is symmetric. In code, solve $Az = b$ with `np.linalg.solve` instead of forming $A^{-1}$.

**How ML uses it.** The normal equations need $(X^\top X)^{-1}$, which fails when features are collinear; ridge adds $\lambda I$ to fix that. In the multivariate Gaussian, $\Sigma^{-1}$ (the precision matrix) sits inside the exponent. A class with no more examples than features has a singular sample covariance, so GDA must regularize it or share one $\Sigma$ across classes.
